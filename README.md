# 🏥 MedCare - Hospital Management System

MedCare is a Hospital Management System built using **Django**. It allows patients to register, book appointments, view lab reports, manage prescriptions, and access healthcare services through a simple and responsive web interface.

----

## 🚀 Features

### 👤 User Authentication
- User Registration
- User Login & Logout
- Change Password
- Secure Authentication

### 🏥 Doctor Management
- View Doctor Profiles
- Doctor Specializations
- Doctor Availability

### 📅 Appointment Management
- Book Appointments
- View Appointment Details
- Manage Appointment Records

### 🧪 Lab Reports
- View Lab Reports
- Download Medical Reports

### 💳 Billing
- View Bills
- Billing History

### 💊 Pharmacy
- View Medicines
- Medicine Information

### 📊 Dashboard
- Personalized Dashboard
- Quick Navigation
- User Information

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/notsneha22/MedCare.git
```

Go into the project folder

```bash
cd MedCare
```

Create Virtual Environment

### Windows

```bash
python -m venv .venv
```
Activate Virtual Environment

```bash
.venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Create Superuser

```bash
python manage.py createsuperuser
```

Run Development Server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
